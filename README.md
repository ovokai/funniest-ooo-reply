Entry for the make.fun competition **Funniest One-Line Out-of-Office Reply**.

See the [bounty page](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) for the competition details.

## What it does

`main.ts` (Node, standard library only) writes one line — an out-of-office
auto-reply with an unusually honest confession about the fate of your email —
to `/output/entry.txt`.

## Run

```sh
node main.ts
```
